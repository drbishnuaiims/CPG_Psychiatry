SEO features included:
- Unique page titles
- Meta descriptions
- Canonical URLs
- Open Graph metadata
- Twitter metadata
- Robots directives
- JSON-LD structured data
- Semantic H1/H2/H3 structure
- Accessible search labels

- Clean static URLs for individual CPG pages
- Mobile responsive design

IMPORTANT BEFORE PUBLISHING

Replace:
https://drbishnuaiims.github.io/CPG_Psychiatry/

with your actual website domain in:
- index.html
- search.html
- cpg/cpg-template.html
- robots.txt
- sitemap.xml

ADDING A NEW CPG

1. Copy:
   cpg/cpg-template.html

2. Rename it:
   cpg/bipolar-disorder.html

3. Change the SEO fields at the top:
   - <title>
   - meta description
   - canonical URL
   - Open Graph title/description/URL
   - Twitter title/description
   - JSON-LD headline/description/URL
   - author name
   - dateModified

4. Change the visible:
   - H1
   - description
   - source
   - year
   - population

5. Replace the sample article body with your AI-generated,
   guideline-specific HTML.

6. Add the new page to js/search.js.

7. Add the new URL to sitemap.xml.

8. Deploy.

CONTENT SEO

For each CPG page:
- Use the exact disorder/guideline name naturally in the H1.
- Use useful H2/H3 headings.
- Write a concise original summary rather than copying the PDF.
- Mention the guideline organization and publication/update year.
- Include references.
- Link to the original guideline where appropriate.
- Do not keyword-stuff.
- Do not create multiple pages with substantially identical content.

SEARCH PAGE

The search page is primarily a navigation tool. Individual CPG pages
are the important SEO landing pages.

MEDICAL CONTENT

These pages are educational notes, not a substitute for the original
guideline or individualized clinical judgment. Keep the source and
publication/update date visible on every CPG page.
